# 공개 안전성 검토

## 공개 기준

난임 시술 데이터는 의료 인접 민감 영역이므로 원본 데이터, 개인정보 가능 자료, 대회 비공개 자료는 공개 대상에서 제외합니다. 저장소는 데이터 처리, 검증 설계, 모델링 판단을 설명하는 포트폴리오입니다.

## 검토 포인트

- 공개 자료: README, 모델링 문서, 공개 가능한 노트북/코드
- 제외 자료: 원본 의료 인접 데이터, 제출 CSV, token, credential, 개인 식별 가능 자료
- 노트북 출력: 원본 행 미리보기, 로컬 경로, 실행 로그를 제거
- 외부 자료: 접근 권한이 필요한 Drive·Notion 원본은 저장소에서 직접 링크하지 않음

## 리뷰어 안내

평가 대상은 민감 데이터 경계를 인식한 tabular ML pipeline 구성과, 실제 대회 기록을 과장하지 않고 남긴 의사결정 근거입니다.
